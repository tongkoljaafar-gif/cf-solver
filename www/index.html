📄 Dokumentasi API

POST /solve — turnstile_v2 (auto-grab sitekey)
# tanpa sitekey manual — solver auto-detect curl -s -X POST :9000/solve -H 'Content-Type: application/json' -d '{ "type": "turnstile_v2", "url": "https://example.com/login", "backend": "camoufox" }' → { "token": "0x4AA…", "elapsed": 3.7, "engine": "camoufox", "sitekey": "..." }
